# Image Sources and Citations

This file contains all image sources and citations for the presentation.
This file follows a specific format to allow automated parsing by `CaptionParser.js`
for generating image captions.
It expects entries in the following pattern:
>`### 'filepath'` the contents between the quotes is the relative path to the image file.   <!-- (' and " allowed) -->  
> `- line 1`  the dash and whitespaces are cut, the result gets internally saved as an array entry  
> `- line 2`  example second line
